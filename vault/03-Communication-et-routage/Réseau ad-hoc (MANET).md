# Réseau ad-hoc (MANET)

> **Définition.** Réseau sans fil qui se forme spontanément, sans infrastructure préexistante, les nœuds jouant eux-mêmes le rôle de routeurs. Mobile Ad-hoc NETwork (MANET) quand les nœuds sont mobiles.

Les réseaux de capteurs sont, par nature, très proches des réseaux ad-hoc :
- **Auto-organisation** : découverte de voisins, construction des routes sans intervention humaine.
- **Absence d'infrastructure** : chaque nœud est terminal *et* routeur.
- **Topologie dynamique** : les liens apparaissent et disparaissent (mobilité, pannes, variations radio).
- **Communication multi-saut** : deux nœuds éloignés dialoguent via une chaîne de relais intermédiaires.
